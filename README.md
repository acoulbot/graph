# Технический каталог товаров

33 позиции · 91 вариант комплектации · 75 документальных изображений

Нейтральный справочный каталог по приложенной таблице. Не рекламные карточки и не готовый комплект для маркетплейсов. Дата проверки: **24 ноября 2026 года**.

## Как читать

Каждый товар разделён на паспорт, комплектацию и галерею; каждая фотография открывается отдельно. Количество упаковок и содержимое показаны раздельно. Закупочные цены, объёмы закупки и накладные исключены.

## Ограничения проверки

- Без фотографий реальных упаковок нельзя окончательно идентифицировать партию.
- У позиций 1, 6, 18 и 21 есть неоднозначности модели или размера. Подробности в паспортах.
- 223 изображения были ориентиром для прежнего рекламного формата. В документальном каталоге количество определяется найденными фотографиями; недостающие ракурсы и наборы не выдуманы.
- Точность вторичных источников и права на коммерческое использование фото не гарантированы.

## Структура проекта

- `catalog/` — отдельные Markdown-страницы.
- `assets/` — найденные документальные фотографии.
- `data/products.json` — данные таблицы без закупочных сведений.
- `data/catalog.json` — характеристики, статусы, источники.
- `data/photos.json` — происхождение изображений и контрольные суммы.
- `RIGHTS.md` — ограничения использования изображений.
